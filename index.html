mAiTV usa TMDB, un database di film e serie gratuito, per mostrarti i titoli di tendenza e quelli disponibili sulle tue app in Italia. Ti serve una chiave personale, gratis:

  1. Crea un account su themoviedb.org
  2. Vai in Impostazioni → API e richiedi una chiave per uso personale
  3. Copia la Chiave API (o il Token di accesso in lettura) e incollala qui
